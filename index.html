FEATURES

一个插件，管住所有「打不开」

Obsidian 原生只认图片、音视频和 PDF。剩下的 Office 文件，交给 Any Viewer。

📎

插入即预览

命令面板选文件、拖拽进笔记、复制后直接粘贴 —— 三种方式都能生成实时预览。

🎨

Excel 样式还原

主题色与淡色填充、字体、边框、对齐、合并单元格、列宽行高、货币百分比格式，原样呈现。

📐

尺寸随心

INSTALL

三种安装方式

推荐官方社区市场；拿不到市场就用 BRAT 或手动安装。

推荐

社区插件市场

设置 → 第三方插件 → 关闭安全模式 → 社区插件市场搜索 Any Viewer → 安装并启用。

搜索关键字：Any Viewer

BRAT

安装并启用 BRAT 插件后，执行命令 Brat: Add Beta Plugin，输入仓库地址。

tingke/obsidian-any-viewer

手动安装

从 GitHub Releases 下载 main.js、styles.css、manifest.json，放入插件目录后重载。

<vault>/.obsidian/plugins/any-viewer/
FAQ

常见问题

需要联网吗？数据会上传吗？

不需要联网，也绝不上传。所有文件都在你的设备上本地解析渲染，适合存放敏感资料的仓库。

支持老版 .doc / .ppt / .xls 吗？

二进制老格式（.doc、.ppt）不支持，请先另存为 .docx / .pptx。.xls 和 .csv / .tsv 表格以简洁表格形式支持。

Excel 的样式能还原到什么程度？

填充色（含主题色与淡色）、字体样式、边框、对齐、合并单元格、列宽行高、数字格式（货币 / 百分比 / 日期）都会还原；图表与条件格式暂不支持。

文件很大会有问题吗？

超大表格默认只渲染前 2000 行 × 80 列并给出提示，点开新标签页可看全量；Word / PPT 大文件建议在标签页中查看。

和其他 Office 预览插件有什么区别？

Any Viewer 用一个插件覆盖 Word / Excel / PPT / HTML / CSV 全格式，并额外提供插入命令、粘贴与拖拽拦截、尺寸语法和文件卡片兜底，不必为每种格式各装一个插件。
